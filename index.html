"Temporary" = Temporary Energy Charge + Meter Cost entries of exactly ₹2,400 / ₹6,000 from the HeadWise report — kept aside, not part of any Collection/Deposite total.
"Total Collection (ID-wise)" = everything for Collector IDs combined — every bill type from Daily Collection (Energy Bill, Assessment, RC/DC, New Service Connection, Testing, Change Process, Meter Seal, all of it) plus every payment mode from Smart Prepaid. Nothing excluded; not split by category.
"Balance" = Total Collection (ID-wise) − (Collection Total + Temporary).
The downloaded Excel file also includes every uploaded source file as its own sheet(s) (Daily Collection, HeadWise, and each Smart Prepaid file), exactly as uploaded, alongside the computed "Collection Report" sheet.
