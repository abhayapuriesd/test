    02 — How it works

    Every sheet from every uploaded file is combined into one output sheet. Columns are matched by header name — if files have columns in different orders, or some files are missing a column, everything still lines up correctly (missing values are left blank). Two extra columns are added at the end: Source File and Sheet Name, so you always know where each row came from. This also works for a single file that has multiple sheets — just upload the one file.
